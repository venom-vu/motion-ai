- (decision) Why: mandate+opportunity. Commercial MVP for VN users to test willingness-to-pay for 1-click AI face swap / body retouch / motion control, GPU spend capped USD 50-100, no idle GPU.
- (capability) CAP-1 Face Swap: 1-click, source_face + target_image -> 1 image, 100 credits, SLA <=60s worker start to R2, no face -> failed + RELEASED 100%. (PRD FR-1, FR-2)
- (capability) CAP-2 Body Retouch: input_image + intensity 1-10 (default 5) -> image keeping face and background, 100 credits, before/after view. (PRD FR-3, FR-4)
- (capability) CAP-3 Motion Control: character_image + pose_video trimmed 3s..tier cap (5/10/15/20), 50 credits/s, live price equals HOLD, output MP4 720p 24fps +-0.5s, no skeleton -> failed + RELEASED. (PRD FR-5, FR-6, FR-7)
- (capability) CAP-4 Credit ledger: immutable ledger, HOLD/CAPTURED/RELEASED per Task, balance=SUM, one HOLD and one terminal entry per Task, never negative under concurrency. (PRD FR-9, FR-10; AD-2, AD-16)
- (capability) CAP-5 Tier and queue: tier from highest pack while total (balance+held)>=100 else FREE, snapshot at create; one shared queue, 2 lanes, priority then FIFO; FREE only when no paid queued, expires after 15 min. (PRD FR-8, FR-11; AD-5, AD-6, AD-10)
- (capability) CAP-6 VietQR top-up: exact-amount QR 15 min, user confirms, admin approves with unique bank_ref within 08:00-23:00 window, credits and tier update atomically. (PRD FR-13, FR-14; AD-13)
- (capability) CAP-7 Signup and trial credit: Google login, 500 credits once per device, max 3 bonus accounts per IP per 24h, 4th+ get 0, no daily or total cap. (PRD FR-12; AD-12)
- (capability) CAP-8 Failure handling: every technical failure ends failed/timed_out/cancelled with automatic RELEASED 100% and UI notice; poor-quality results not auto-refunded, admin compensates manually. (PRD FR-15, FR-16, FR-17; AD-4..AD-7)
- (capability) CAP-9 Operational protection: breaker pauses Task creation (503) at >15% system failures over 30 min with >=20 tasks or 5 consecutive; Discord alerts for new VietQR order, breaker, RunningHub balance <USD 15; budget exhaustion fails queued tasks fast, top-ups and downloads keep working. (PRD FR-18; AD-14)
- (capability) CAP-10 Compliance: ToS consent at signup, top-up and each upload with version stored; admin account lock; report link and instant R2 takedown. (PRD FR-19, FR-21, FR-22; AD-18)
- (capability) CAP-11 Results and sharing: results copied to R2 with EXIF AI tag, private bucket with signed URLs, sharing only via user-created token, retention inputs 7d / outputs 30d. (PRD FR-2, NFR-2, NFR-6; AD-7, AD-8)
- (capability) CAP-12 Pre-launch gate: operator verifies unit economics and infra before enabling commercial VietQR: benchmark 10 images + 10 videos plus 1-2 sensitive images, Creator margin >=70%, 0% technical failures, 5 infra tests. (PRD section 12)
- (constraint) Stack fixed: Nuxt 4 on Cloudflare Pages; NestJS api+worker; PostgreSQL 16 container; Redis 7; Cloudflare R2; single VPS 4 vCPU/8GB with exactly 4 containers; Cloudflare Proxy with Origin CA, ufw only Cloudflare ranges. No GPU server.
- (constraint) Prices: image 100 credits, video 50 credits/s, min 3s, caps FREE 5/Starter 10/Pro 15/Creator 20s; packs 49k/99k/199k VND = 5,000/12,000/30,000 credits, no expiry; trial 500.
- (constraint) RunningHub: poll every 3s via /task/openapi/outputs, no webhook; timeouts image 180s, video 360s from upload start, prep 120s; orphan window 10 min; no idempotency key so never resubmit; face/pose detection in workflow after HOLD.
- (constraint) Task state authority is PostgreSQL compare-and-set; Redis is hint only; money and status change in the same transaction.
- (constraint) Content safety in MVP rests on ToS, RunningHub built-in filter node (CONTENT_BLOCKED, error string unknown until benchmark), report/takedown. nsfwjs Pre-check deferred to v2 for workload. Minors detection has no technical solution.
- (constraint) Scope: VN-only, Vietnamese UI, 18+, manual VietQR approval, ffmpeg trim re-encode libx264 veryfast 24fps one process at a time, image long edge resized to 2048, video input <=100MB MP4/MOV.
- (decision) Non-goals taken from PRD 7.2 plus: no auto bank reconciliation, no cards/i18n, no Face Swap on video, no batch/API, no native app, no real-money refunds, no C2PA, no support ticket system, no output moderation, no staging.
